# D’Nata — Quesos de Bambamarca

Página estática en HTML y JavaScript, con CSS incluido en `index.html`. Sin frameworks, paquetes ni compilación.

## Ver la página

Abre `index.html` en tu navegador. También puedes servir la carpeta con cualquier servidor de archivos estáticos.

## Deploy

En Netlify, Vercel u otro alojamiento estático:

- Comando de compilación: ninguno.
- Directorio de publicación: la raíz del repositorio (`.`).
- Página de entrada: `index.html`.

En GitHub Pages: selecciona la rama `main` y la carpeta `/ (root)` en Settings → Pages cuando quieras publicarla. Este repositorio no activa despliegues automáticos.

## Efectos y accesibilidad

- El queso de la portada aumenta de tamaño al desplazarse, con rotación y desplazamiento suaves.
- Barra de progreso de lectura y aparición de secciones.
- Menú móvil, enlaces internos y preguntas desplegables.
- Respeta `prefers-reduced-motion`; navegación por teclado y enlace para saltar al contenido.
- Diseño adaptable a móvil y escritorio. Las fuentes de Google son opcionales: hay fuentes de sistema de respaldo.

## Contenido y foto

El contenido usa la foto de referencia y el origen proporcionado por el solicitante. La etiqueta dice Bambamarca (Cajamarca, Perú), D’Nata y Agroindustrias PROLACB S.A.C.; declara leche fresca entera, cuajo, sal y 300 g. Las ideas para servir son sugerencias editoriales. No se inventaron cifras, testimonios, canales de venta ni datos de contacto.

`assets/queso.png` es una adaptación de la foto de referencia mediante IA para aislar el producto y retirar el fondo. La reproducción de la etiqueta puede contener variaciones: revisar el arte y las afirmaciones de producto antes de un lanzamiento comercial.
